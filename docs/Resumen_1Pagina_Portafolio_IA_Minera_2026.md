# RESUMEN EJECUTIVO 1 PAGINA

## Seleccion de Portafolio IA para Plataforma Minera 2026

**Audiencia**: Directorio, Gerencia General y Gerencia TI  
**Fecha**: 15 de mayo de 2026  
**Objetivo**: Aprobar la estrategia de adopcion de IA para la nueva plataforma minera en VPS, la continuidad de la plataforma actual en AWS y la productividad compartida de ingenieria.

---

## 1. Decision recomendada

No se recomienda adoptar una sola plataforma de IA. Se recomienda aprobar un **portafolio multivendor, gobernado por TI**, con una capa comun de acceso para todos los ingenieros y proyectos.

## 2. Que problema resuelve

La empresa necesita cubrir simultaneamente:

1. Construccion de la nueva plataforma minera sobre VPS con respaldo AWS.
2. Mantenimiento evolutivo de la plataforma actual.
3. Productividad de ingenieros que trabajan en varios proyectos de automatizacion minera.
4. Document AI, RAG, biometria, telemetria, ciberseguridad y prediccion de eventos.

## 3. Recomendacion sintetica

| Capa | Recomendacion |
|---|---|
| Copiloto corporativo base | GitHub Copilot |
| Capa senior de desarrollo | Claude Code Team o Windsurf Teams |
| Modelos premium | Claude Sonnet 4.6 / GPT-5.4 |
| Modelos de alto volumen | Gemini 2.5 Flash / Flash-Lite |
| Portabilidad y hybrid | Mistral Medium 3.1 / Codestral |
| Continuidad AWS | Amazon Bedrock |
| Prediccion minera | PyTorch + XGBoost + MLflow |

## 4. Mensaje clave para directorio

El valor no esta en comprar licencias aisladas. El valor esta en crear una **plataforma compartida de capacidades IA**, reutilizable entre equipos, con control de costo, gobierno de datos, seguridad y observabilidad.

## 5. Presupuesto orientativo inicial

### Productividad de ingenieria

1. 25 licencias base de copiloto: referencia desde USD 250/mes si se toma como base GitHub Copilot Pro.
2. 8 licencias premium senior: referencia entre USD 320/mes con Windsurf Teams y USD 1,200/mes con Claude Code Team.

### Consumo API inicial mensual

1. Fase de arranque y PoC: USD 500 a USD 1,500 / mes.
2. Fase operativa con RAG, document AI y asistentes: USD 1,500 a USD 4,000 / mes.
3. Fase avanzada con mayor carga y evaluacion continua: USD 4,000 a USD 8,000 / mes.

## 6. Beneficio esperado

1. Menor tiempo de desarrollo y mantenimiento.
2. Mejor calidad documental y tecnica.
3. Mayor capacidad de analisis operativo y soporte a telemetria.
4. Base tecnica correcta para evolucionar hacia modelos predictivos mineros propios.

## 7. Decision sugerida

Autorizar un programa en tres frentes:

1. Copilotos y gateway multi-modelo.
2. Document AI y RAG corporativo.
3. Plataforma de ML para prediccion de eventos y analitica minera.

La recomendacion final es aprobar la estrategia **multivendor, gobernada y compartida**, porque es la que mejor equilibra costo, control, continuidad y capacidad de evolucion para la empresa.
