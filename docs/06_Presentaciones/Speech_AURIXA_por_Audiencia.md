# SPEECH AURIXA POR AUDIENCIA

## Version para Gerencia General

Buenos dias.

La recomendacion que traemos hoy es aprobar una base de proyecto que fortalece tres cosas clave para la compania: control operacional, continuidad del negocio y trazabilidad ejecutiva.

Hoy la informacion critica de operacion y seguimiento esta mas dispersa de lo conveniente. AURIXA ordena ese frente en una sola plataforma, con hitos de control, entregables verificables y una arquitectura pensada para operar con mayor autonomia y menor dependencia externa.

Lo importante para gerencia no es solo la tecnologia. Es que este SOW convierte una necesidad operativa en un plan gobernable, con mayor claridad sobre alcance, riesgos, responsables e inversion.

Mi recomendacion es aprobar la base para firma, porque permite tomar una decision con mejor visibilidad y dejar instalada una capacidad real de gestion para la compania.

## Version para Gerencia TI

Buenos dias.

Desde la perspectiva de TI, este SOW ordena el proyecto en los frentes que mas importan para una salida responsable: arquitectura, integracion, seguridad, aceptacion, gobierno de cambios y paso controlado a produccion.

AURIXA no se plantea como un desarrollo aislado. Se plantea como una plataforma operativa con trazabilidad, trabajo offline, integracion con fuentes autorizadas, hardening, UAT y criterios claros de aceptacion por hito.

La arquitectura soberana en Lima responde a necesidades concretas de latencia, control de informacion y continuidad operativa. Ademas, la ejecucion en dos etapas reduce riesgo, porque primero valida el core funcional y luego endurece la plataforma antes del go-live.

Mi recomendacion es aprobar esta base de cierre para firma, porque entrega un marco tecnico y de gestion suficientemente claro para avanzar con control y sin ambiguedades.
