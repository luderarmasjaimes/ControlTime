# SPEECH EJECUTIVO - AURIXA

## Presentacion de 2 minutos para Gerencia General y Gerencia TI

Buenos dias.

El documento que presento hoy no busca solo aprobar un desarrollo tecnologico. Busca ordenar una decision de negocio y de operacion sobre un frente critico para la compania.

Hoy tenemos un problema estructural: la informacion operativa, la trazabilidad documental, la evidencia tecnica y la supervision de eventos no conviven en una sola plataforma gobernable. Eso genera dispersion, dependencia de herramientas generales, menor control y mayor dificultad para gestionar continuidad operativa con criterio ejecutivo.

AURIXA responde a ese problema proponiendo una plataforma integral para operacion minera, construida en dos etapas durante 26 semanas. La primera etapa asegura el nucleo funcional: editor operativo, trazabilidad, integracion, mapas, sensores y trabajo offline. La segunda etapa lleva esa base a condiciones reales de operacion: hardening, seguridad, inteligencia artificial priorizada, UAT, marcha blanca y salida controlada a produccion.

La arquitectura propuesta en Lima responde a una necesidad concreta: menor latencia, mayor soberania de la informacion, menor dependencia externa para procesos core y mejor gobernabilidad para TI y para la operacion.

Desde el punto de vista de gestion, este SOW ordena el proyecto por hitos, entregables, criterios de aceptacion, riesgos, dependencias y gobierno. Eso significa que la gerencia no estaria aprobando una idea abierta, sino un plan controlable, medible y trazable.

Desde el punto de vista economico, tambien hemos sincerado la lectura del proyecto. Ya no mostramos solo un costo tecnico base, sino un presupuesto mas realista que incorpora equipamiento y costos laborales adicionales, para que la decision tenga mejor visibilidad financiera.

Mi recomendacion es aprobar este documento como base de cierre para firma, porque permite pasar de un avance tecnico disperso a una implementacion gobernada, con mayor control operacional, continuidad del negocio y trazabilidad ejecutiva.

Ese es el valor principal de AURIXA: no solo construir una solucion, sino dejar capacidad real de gestion para la compania.
