# SPEECH EJECUTIVO - AURIXA

## Version de 60 segundos para apertura de reunion

Buenos dias.

Lo que hoy se presenta para aprobacion no es solo un desarrollo tecnologico. Es una decision para ordenar control operacional, continuidad del negocio y trazabilidad sobre un frente critico para la compania.

AURIXA propone consolidar en una sola plataforma la informacion operativa, la evidencia tecnica, el monitoreo de eventos, la gestion documental y el trabajo offline, bajo una arquitectura soberana en Lima y una ejecucion por etapas durante 26 semanas.

El valor de este SOW es que convierte una iniciativa tecnica en un proyecto gobernable: define alcance, hitos, criterios de aceptacion, riesgos, responsables y una lectura economica mas realista para decidir con mayor visibilidad.

Mi recomendacion es aprobar esta base para cierre de firma, porque permite pasar de un avance disperso a una implementacion controlada, con beneficios directos en control, continuidad y capacidad de gestion para la operacion minera.
