1. Arquitectura General Conceptual del Frontend

El portal web adopta el paradigma Single-Page Application (SPA), construido sobre el framework React 18 y empaquetado mediante Vite para lograr Hot-Module-Replacement (HMR) y construcciones minificadas hiper-velozes. La interfaz rechaza los recargos de página para ofrecer una experiencia que emula a una aplicación nativa instalada.

2. Estructuración Detallada por Funcionalidades Clave

Módulo: AuthGateway & Biometría Cero-Toque

  • WebRTC / navigator.mediaDevices: Solicitud de hardware de video en tiempo real, operando estrictamente dentro de un canvas.
  • UI Oval ICAO: Overlay renderizado sobre el video que empuja al usuario a "centrar" su rostro evaluando dimensiones geométricas mínimas (Pitch, Yaw, Roll, iluminación) requeridas por la IA.
  • Fallback Mecánico: Alternancia programática fluida al login con contraseña cuando el ambiente no sea idóneo (oscuridad profunda, casco, bloqueos de seguridad PWA).

Módulo: ReportStudioV2 (Administración & Control)

  • Mantenimiento de Usuarios (UserManagementView.jsx): Tabla de despliegue hiper denso (Tailwind) donde los administradores inhabilitan cuentas y mutan perfiles utilizando la matriz unificada USER_ROLES.
  • Gestión de Permisos (PermissionsManagementView.jsx): Interfaz transaccional (Matriz) que sincroniza a la base de datos PostgreSQL exactamente qué funcionalidad (ej. `telemetry.read`) posee cada Rol Oficial. Generada dinámicamente con las constantes importadas desde `roleConstants.js`.

Módulo: GIS & Especializados (MapViewer)

  • Leaflet.js: El lienzo geográfico, altamente parametrizable y capaz de inyectar FeatureCollections de GeoJSON.
  • Capas Poligonales y Oficiales: Superposición asíncrona de concesiones mineras, galerías subterráneas y geo-cercos de seguridad obtenidos por los microservicios, cruzados contra un servidor local de mapas `mbtiles`.

3. Flujo Biométrico y Arquitectura Temporal de Componentes UI

La orquestación de vida para el registro y conexión (Onboarding) involucra captura continua y descarte rápido de frames. El frontend nunca procesa machine learning, el frontend audita calidad bruta y la transmite codificada (Base64) al servidor.

4. Reactividad UI, Telemetría, GIS Y Matrix State

El desafío crucial arquitectónico del frontend empresarial LATAM es pintar interfaces de datos en "Tiempo Real" (Real-Time) sin romper la fluidez (bloquar el main thread del navegador). Usamos sincronizaciones de estado atómico y promesas asíncronas.

    [*] -> Leer_AuthStorage
    Leer_AuthStorage --> Parsear_User_Role : Si Existe Token (JWT Valido)

    Parsear_User_Role -> Evaluar_Privilegios
}

Boot_Sequence --> AuthGateway : Token Nulo / Fallido
AuthGateway : Activa Video / Formularios / Animaciones Framer

Boot_Sequence --> Dashboard_Core : Token OK (Autorizado)

state Dashboard_Core {
    state "Módulo ReportStudioV2" as ADMIN {
        state "Matriz de Permisos" as PERM
        PERM : Pinta tabla bidimensional NxM basado en USER_ROLES y Endpoints HTTP
        state "Visión Usuario" as USRV
        USRV : CRUD Reactivo usando componentes visuales (Lucide-icons / Modales).
    }
    
    state "Módulo Geométrico/GIS" as MAPAS {
        state "MapViewer Leaflet" as LEAF
        LEAF : 1. Carga Vector Tiles Externos
        LEAF : 2. Dibuja Polígonos de Seguridad Oficial (Inclinometría y Lidar)
    }

    state "Módulo Telemetría Dashboard" as DASH {
        state "Gráficos Recharts" as CHARTS
        CHARTS : Render Optimizado. Dificulta los Reflows del DOM.
        state "WebSockets (CCTV / Sensores)" as WSS
        WSS : Socket OnMessage -> Update Local State -> Re-render parcial 
    }
    
    ADMIN -[#hidden]-> MAPAS
    MAPAS -[#hidden]-> DASH
}

Dashboard_Core --> [*] : Logout Action / Flush Store

Detalle de Estándares Visuales Empresariales:

La directriz de la arquitectura obliga a mantener un formato Premium:

  • Tailwind Token System: Uso extensivo de paletas oscuras (bg-slate-900, bg-gray-800), efectos hiper-nativos "Glassmorphism" con bordes semitransparentes mediante la semántica utilitaria sin acoplar CSS modular.
  • RBAC Acoplado ( roleConstants.js ): La arquitectura resolvió los errores de disparidad entre roles (ej. 'Jefe de Area' vs 'Supervisor') con una matriz inmutable cargada desde USER_ROLES, siendo absorbida por la vista administrativa (UserMaintenanceModal.jsx) así como por la interfaz de permisos (PermissionsManagementView.jsx), asegurando precisión total y robustez militar sin huecos de seguridad UI.
  • Ruteador Tolerante (Guards): Si una cuenta de jerarquía reducida (`Operador / Téc.`) navega a fuerza bruta a la ruta cartográfica de auditorías gerenciales (`/admin/permissions`), el árbol de React en forma de 'Wrapper Guard' expulsa la conexión hacia el Dashboard evitando filtraciones.
