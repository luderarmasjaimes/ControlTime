# Version Comercial del Cronograma
## Plataforma Minera sobre VPS Linux en Lima

**Propuesta de valor**
La planificacion de 26 semanas organiza el proyecto en dos etapas para entregar valor temprano, controlar el riesgo de salida a produccion y asegurar una implementacion ejecutable sobre VPS Linux en Lima, sin crear una nueva arquitectura en AWS.

## Mensaje Comercial Principal
- La nueva plataforma se implementa sobre infraestructura controlada en Lima.
- Se reduce dependencia de costos variables de una nueva nube publica para este proyecto.
- La integracion con la plataforma actual en AWS se mantiene de forma controlada para no interrumpir el negocio.
- El cliente recibe una hoja de ruta con hitos, entregables, riesgos y responsables claramente definidos.

## Estructura de la Oferta
**Etapa 1: Implementacion Funcional Core**
- Duracion referencial: 4 meses
- Objetivo: construir el nucleo funcional, editor documental, tablero gerencial e integracion base.

**Etapa 2: Hardening, Estabilizacion y Go-Live**
- Duracion referencial: 2 meses
- Objetivo: endurecer la plataforma, validar continuidad, ejecutar UAT y completar la salida a produccion.

## Beneficios para el Cliente
- Mayor control sobre datos y operacion.
- Costos mas previsibles en infraestructura.
- Mejor tiempo de respuesta desde Lima.
- Menor complejidad de despliegue que una reconstruccion completa en cloud publico.
- Cronograma con foco en entregables reales y no solo en actividades tecnicas.

## Hitos Comerciales Clave
- Arquitectura aprobada y plan de gobierno formalizado.
- Editor maestro y tablero gerencial funcionales.
- Integracion estable con la plataforma actual.
- Hardening y continuidad operativa validados.
- Go-live con transferencia formal y acompanamiento.

## Riesgos Gestionados
- Dependencia de la base externa actual en AWS.
- Rendimiento de la nueva infraestructura VPS.
- Cierre de seguridad y continuidad antes del go-live.
- Adopcion de usuarios durante marcha blanca.

## Cierre Comercial
Esta planificacion posiciona el proyecto como una implementacion controlada, escalable y ejecutiva, orientada a resultados visibles para la gerencia y con una ruta de salida a produccion realista para una operacion minera exigente.
