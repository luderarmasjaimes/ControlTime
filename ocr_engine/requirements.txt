# PTX con una variable de entorno especial, y que subir a TF 2.18 para
# alinear cuDNN rompió por falta de kernels CUDA para Blackwell
# (CUDA_ERROR_INVALID_PTX real, confirmado en runtime). Instalar acá una
# wheel GPU no verificada arriesgaría la misma falla silenciosa. Server.py
# deja OCR_ENGINE_USE_GPU=1 como interruptor para cuando alguien confirme una
# wheel compatible; por defecto CPU (aceptable: esto es una operación de
# importación bajo demanda con indicador de progreso en el frontend, no un
# camino caliente como el verify-frame de login de silentface_engine).
