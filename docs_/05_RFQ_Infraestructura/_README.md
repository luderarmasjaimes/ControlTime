# 05 · RFQ e Infraestructura (Datacenter Lima)

Paquete de **solicitud de cotización (RFQ)** y selección de infraestructura para la arquitectura soberana **VPS/datacenter en Lima** (SOW v4, Etapa 2). Sustituye el enfoque cloud AWS, que se mantiene solo como fuente de datos.

| `Plantilla_Comparacion_Economica_Datacenter_AURIXA` (.csv/.xlsx) | Plantilla de comparación de costos |
