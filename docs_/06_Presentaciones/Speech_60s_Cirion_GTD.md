# SPEECH 60 SEGUNDOS - DEFENSA CIRION + GTD

La recomendacion de arquitectura para AURIXA es trabajar con **Cirion como sitio primario** y **GTD Lurin como sitio secundario**.

La razon principal es que esta combinacion entrega el mejor equilibrio entre **control, continuidad y resiliencia** para una plataforma minera 24x7.

Cirion nos da un entorno fuerte en Lima metropolitana, con perfil enterprise, conectividad y condiciones adecuadas para operar la carga principal. GTD Lurin complementa esa base con una segunda ubicacion robusta, separada y adecuada para contingencia o disaster recovery serio.

Lo importante para gerencia es que aqui no estamos recomendando solo un proveedor. Estamos recomendando una arquitectura que reduce dependencia de un unico sitio, mejora la capacidad de recuperacion ante fallas y permite evaluar la migracion con criterios empresariales reales.

En consecuencia, la base sugerida para RFQ y negociacion debe ser **Cirion primario más GTD secundario**, porque es la alternativa que mejor protege la continuidad operativa y el control de una plataforma critica para la compania.
