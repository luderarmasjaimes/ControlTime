# ROADMAP TRIMESTRAL

## Programa de Adopcion IA para Plataforma Minera 2026

**Fecha**: 15 de mayo de 2026  
**Dirigido a**: Gerencia General y Gerencia TI  
**Objetivo**: Organizar la adopcion de IA por fases, responsables y presupuesto referencial.

---

## 1. Enfoque general

El programa debe implementarse por trimestres para controlar riesgo, gasto y capacidad de absorcion organizacional. El objetivo no es desplegar todo al mismo tiempo, sino construir una plataforma de IA reutilizable, gobernada y medible.

## 2. Roadmap por trimestre

### Trimestre 1 - Fundacion y productividad

**Objetivo**: activar la capa base de productividad y gobierno.

| Frente | Actividades principales | Equipo lider |
|---|---|---|
| Copilotos | Despliegue de GitHub Copilot, pilotos con Claude Code o Windsurf | Arquitectura + Desarrollo |
| Gateway IA | Implementacion de gateway multi-modelo y politicas de acceso | Arquitectura + DevOps |
| Seguridad | Gestion de llaves, auditoria, cuotas y politicas basicas | Seguridad + DevOps |
| RAG inicial | Repositorio documental base y embeddings iniciales | Desarrollo + Datos |

**Presupuesto referencial trimestral**:

1. Licencias base: USD 750.
2. Licencias premium: USD 960 a USD 3,600.
3. API y pruebas: USD 1,500 a USD 3,000.
4. Infraestructura y observabilidad: USD 1,000 a USD 2,000.

**Rango total T1**: **USD 4,210 a USD 9,350**.

### Trimestre 2 - Document AI, operacion y continuidad

**Objetivo**: industrializar document AI, asistentes internos y soporte operativo.

| Frente | Actividades principales | Equipo lider |
|---|---|---|
| Document AI | OCR, clasificacion documental, correccion y RAG | Desarrollo + Datos |
| Copilotos operativos | Resumen de eventos, tickets, telemetria y reportes | Desarrollo + Operaciones |
| Plataforma AWS/VPS | Integracion de IA con nueva plataforma VPS y continuidad AWS | Arquitectura + DevOps |
| Observabilidad | Trazas, costos, evaluacion y metricas de uso | DevOps + Arquitectura |

**Presupuesto referencial trimestral**:

1. Licencias base y premium: USD 1,710 a USD 4,350.
2. API operativa: USD 4,500 a USD 9,000.
3. OCR, embeddings, vector store y storage: USD 1,500 a USD 4,000.
4. Observabilidad y seguridad: USD 1,500 a USD 3,000.

**Rango total T2**: **USD 9,210 a USD 20,350**.

### Trimestre 3 - Analitica minera y prediccion

**Objetivo**: habilitar la plataforma de entrenamiento y despliegue de modelos mineros propios.

| Frente | Actividades principales | Equipo lider |
|---|---|---|
| ML Platform | MLflow, datasets, features, experiment tracking | Datos + Arquitectura |
| Prediccion de eventos | Baselines con XGBoost, LightGBM y PyTorch | Datos + Especialistas mineros |
| Vision y biometria | Industrializacion de pipelines faciales y validacion operativa | IA Python + Seguridad |
| MLOps | Versionado, evaluacion, despliegue y monitoreo de modelos | DevOps + Datos |

**Presupuesto referencial trimestral**:

1. Licencias base y premium: USD 1,710 a USD 4,350.
2. API generativa y evaluacion: USD 6,000 a USD 12,000.
3. Plataforma ML y compute: USD 4,000 a USD 12,000.
4. Datos, almacenamiento y monitoreo: USD 2,500 a USD 6,000.

**Rango total T3**: **USD 14,210 a USD 34,350**.

### Trimestre 4 - Escalamiento y gobierno corporativo

**Objetivo**: consolidar estandar corporativo y expandir a proyectos mineros adicionales.

| Frente | Actividades principales | Equipo lider |
|---|---|---|
| Gobierno | Politicas finales, catalogo de agentes y auditoria central | Arquitectura + Seguridad |
| Escalamiento | Expansion a otras areas y proyectos de automatizacion | Gerencia TI + Arquitectura |
| Optimizacion | Ajuste de TCO, caching, routing y FinOps IA | Arquitectura + DevOps |
| Continuidad | Mayor integracion entre VPS principal y AWS respaldo | DevOps + Infraestructura |

**Presupuesto referencial trimestral**:

1. Licencias y adopcion extendida: USD 2,500 a USD 6,000.
2. API y workloads productivos: USD 8,000 a USD 18,000.
3. Gobierno, seguridad y observabilidad: USD 3,000 a USD 7,000.
4. Escalamiento e integraciones: USD 3,000 a USD 8,000.

**Rango total T4**: **USD 16,500 a USD 39,000**.

## 4. Equipos y capacidades requeridas

| Equipo | Rol en el programa |
|---|---|
| Arquitectura TI | Gobierno, vendor selection, referencia tecnica |
| Desarrollo JS/React/Python | Integracion con aplicaciones y copilotos |
| DevOps | CI/CD, gateway, seguridad, observabilidad |
| Datos / IA | RAG, embeddings, entrenamiento y evaluacion |
| Operaciones mineras | Validacion funcional y casos de uso |
| Seguridad | Politicas, auditoria y control de acceso |

## 5. Recomendacion final

El roadmap debe aprobarse como un programa de modernizacion gradual, no como compra aislada de licencias. La ruta correcta es empezar por productividad y gobierno, luego document AI y asistentes, y finalmente evolucionar hacia modelos predictivos propios para industria minera.
