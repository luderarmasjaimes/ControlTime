0. Configuración requerido primero

Esta página se sirve intencionalmente en un origen distinto (puerto propio) al del backend, para simular una aplicación externa real. Si el backend rechaza las peticiones, agregue el origen exacto de esta página (protocolo+host+puerto, visible arriba en origin) a la variable de entorno BEEMETRY_CORS_ALLOWED_ORIGIN del backend (lista separada por comas) y reinicie el contenedor.
